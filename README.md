# Intern Portal Frontend

A responsive frontend dashboard for an Intern Portal application.

## Features

* Intern dashboard interface
* Clean and responsive UI
* Displays intern information
* User-friendly navigation
* Frontend integration with backend services

## Technologies

* HTML
* CSS
* JavaScript

## Project Structure

The project contains the frontend interface and supporting assets required for the Intern Portal.

## Purpose

This project was developed to practice frontend development, dashboard design, and integration with backend functionality.
