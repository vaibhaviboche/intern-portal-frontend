# Intern Portal Frontend

A responsive frontend interface for an **Intern Portal** application that displays intern information and connects with backend services through an API.

## ✨ Features

* Intern dashboard interface
* Clean and responsive user interface
* Displays intern information dynamically
* API integration with backend services
* Refresh data functionality
* Simple and user-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Fetch API
* REST API

## 🔗 Live Demo

## 🔌 Backend Integration

The frontend uses JavaScript to communicate with the backend API and retrieve intern information.

The received data is displayed dynamically on the dashboard.

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/vaibhaviboche/intern-portal-frontend.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.
